# 看房速算（fang-calc）

看到物件當天用的判斷工具。填物件 → 立刻知道「能不能買」和「買得起嗎」。

## 來源

公式與欄位來自 Joan 的 `投資計算表.xlsx`（桌面），把散在四支工具的東西併成一支：

| 原本 | 做什麼 | 已併入 |
|---|---|---|
| 投資計算表.xlsx | 物件投報評估 | ✅ 主結構、成本八項、ROI、三家銀行估價 |
| sell-calc | 賣三重拿多少 | 「賣三重淨到手」欄位 |
| home-calc | 家庭現金流 | 月現金流 |
| 換屋資金計畫 | 買得起嗎 | 資金來源與出價上限 |

## 驗證（2026-09-21）

用 Playwright 讀畫面數字，對照 xlsx 三個案子逐項比對：

| 物件 | ROI | 總投入 | 月現金流 |
|---|---|---|---|
| 五華街 | 11.6% = 11.61% | 370.5 = 370.51 | +3.6 = 3.59 |
| 四川路 | 12.0% = 12.01% | 611.1 = 611.07 | +6.1 = 6.12 |
| 案件 | 9.7% = 9.72% | 412.1 = 412.11 | +3.3 = 3.34 |

全部相符。

## 口徑說明

- **貸款基數**：開價與估價平均取「較低」那個（xlsx 步驟表 step 4）
- **ROI／月現金流**：主顯示跟 xlsx 一致（只扣利息）；副標註連二順位本金一起扣的實付數字
- **介紹費**：固定金額（各案個別談，非固定比率）
- **二順位**：固定月付 1 萬

## 維護

改公式或版面改 `template.html`，然後 `python build.py` 重新嵌入舊案資料。
要更新舊案：`python extract.py` 重讀 xlsx。
